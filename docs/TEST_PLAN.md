# 回归测试与验收

目的：保留已确认的玩耍规则，让改音色、改画面、扩词库时能发现真实回归。
测试按行为分类；画面允许正常美术调整，不把一张固定截图当作唯一正确输出。

## 本机自动测试

执行 `./scripts/test.sh`，不需要连接设备或生成语音。

| 用例 | 预期 | 所在文件 |
| --- | --- | --- |
| 同键及大小写 | 同一个键颜色、动画类型和音色稳定；不同字母组合可区分 | `tests/input_session_test.cpp` |
| 停顿边界 | 截止前不结束，到截止时结束；自定义时间生效 | 同上 |
| 长按与重新输入 | 持续按住推迟截止；新输入重置计时 | 同上 |
| 退格、无效输入、溢出 | 正常删除；标点、空格和超长输入不能意外识别为单词 | 同上 |
| 时钟回绕 | 32 位毫秒计时回绕后仍正确 | 同上 |
| 按键音回归 | 20 段音效起音 RMS 足够、峰值受限、起止平滑，频率处于小扬声器可用中频 | 两个测试文件 |
| 扩词库不丢旧词 | 保留原有单词及新增类别代表词，排序、去重、长度合法 | `tests/test_assets.py` |
| 素材完整 | 每个词都有语音和已实现图案；采样数、PCM 校验和与清单一致 | 同上 |
| USB 截图事件 | 截图前到达的语音结束消息被保留，像素完整，错误尺寸被拒绝 | `tests/test_usb_frame.py` |
| 生成器一致 | 当前生成器产生的音效与提交素材一致；修改音色后重新生成即可通过 | 同上 |

不固定要求词库必须等于 143，允许后续继续增加。需要删除词时应先明确产品含义，再调整对应契约。
音量设置为零允许静音；音频参数测试针对素材，不能证明扬声器实际音压或用户听感。

## 真机自动测试

先编译、刷写，再依次运行。测试期间不要按实体键盘；默认静音运行真实播放链路，结束后恢复正常音量。

```sh
./scripts/pio.sh run
./scripts/pio.sh run --target upload --upload-port /dev/cu.usbmodem101
./.venv/bin/python scripts/hardware_test.py
./.venv/bin/python scripts/play_regression.py
```

| 用例 | 预期 |
| --- | --- |
| 3 秒朗读 | 最后输入后 3000–3100 ms 开始匹配词语音；只读一次 |
| 精确匹配 | `xxcat`、`cat1`、`cat dog`、超长输入均不读 |
| 设置持久化 | 修改等待时间，保存重启仍生效；测试结束恢复原值 |
| 快速敲按 | 100 次注入后画面仍更新、堆内存无明显下降 |
| 临时静音 | 测试及测试内重启后均启用静音；结束时正常音量恢复、保存的音量不变 |
| 全部按键音 | 20 种音效都开始实际播放，短音结束后通道恢复空闲 |
| 四类动效 | a/b/c/d 的两帧中央有明显变化；底部输入栏保持一致 |
| 新词场景 | 大象、兔子、西瓜、火车、彩虹、书、手、数字十、蝴蝶、火箭、睡觉、草莓正确触发图案及语音 |
| 打断恢复 | 朗读期间新按键停止语音，并立即开始按键音；新输入保留 |

日志：`artifacts/hardware-test.log`、`artifacts/play-regression/test.log`。默认只打印测试进度；设置 `TOY_TEST_VERBOSE=1` 可打印全部串口事件，避免大量标准输出阻塞短音时序测试。
画面：`artifacts/play-regression/*.ppm`，是设备实际绘制帧；需要人工检查构图、语义与可读性。

## 必须人工试听／操作

- 用设备实体键盘依次按 a、b、c、d：四种声音应清楚可听、柔和、不刺耳。
- 输入 `cat`，松手 3 秒：英文清晰；朗读期间再按键应立即有短音。
- 快速乱按和同时按多个键，不应出现积压的长串声音；长按只响一次。
- 长按 G0 进入设置，调整音量可即时试听，保存/取消行为符合预期。
- 脱离 USB、侧面电源保持 ON，仍能正常玩耍。

自动测试不能替代这些人工结果，尤其不能把“播放接口成功”报告为“听感已确认”。

## 1.4 新功能验收

`./scripts/test.sh` 增加渐暗边界、渐变单调性、关闭、按住保持亮屏、唤醒、计时回绕，以及旧设置结构迁移的 C++ 测试。

执行 `./.venv/bin/python scripts/features_test.py`（默认静音，约 3 分钟）：

- 从家长菜单打开图鉴，验证前后首尾循环、翻页不发声且不加入输入缓冲。
- 逐页导出全部 143 个单词的真实绘制帧；另存 9 类情景动画的后续帧用于构图及运动检查。
- 图鉴停留超过 4.5 秒仍保持打开；手动试听能开始并正常结束。
- 在菜单设置 30 秒渐暗，重启检查持久化，且原音量、亮度、停顿保持不变。
- 等待真实闲置时间，观测背光逐渐下降到 20；第一下唤醒按键同时产生文本和音效。
- 关闭渐暗后等待 32 秒，确认维持正常亮度；最后恢复用户全部原设置。

设备日志与画面放在 `artifacts/features-1.4/`。按键交互与人耳听感仍需人工体验，自动验证全程静音。

# Little Wonders：目标与已确认偏好

这份文档用于后续开发延续用户意图。它区分产品要求和当前实现参数，避免把实现细节当作永久约束。
用户最新明确指令优先；方向有变化时更新本文，并保留足够的解释。

## 为谁做、为什么做

给约 **2 岁的小孩**玩。孩子主要对声音、动画和按下按键后的即时变化感兴趣，通常会随机敲按。

核心体验是：**按一下就有轻柔、有趣、能对应到按键的反馈**。
孩子不需要认识字母、拼对单词、完成任务或理解菜单。即使从来没有拼出单词，玩具本身也应有趣。
英文朗读是一个附加的小惊喜，不把玩具设计成有对错压力的学习测验。

目标硬件：用户通过 USB 连接的 **M5Stack Cardputer ADV**，240 × 135 屏幕、实体键盘和内置扬声器。
部署和开发都以此项目目录为中心，开发后设备可脱离电脑独立玩耍。

## 当前交互规则

| 时机 | 已确认行为 |
| --- | --- |
| 按下按键 | 立即播放短音效，中央出现当前字母或特殊键的反馈动画 |
| 连续输入 | 底部累积显示本轮内容，如 `c` → `ca` → `cat`；中央突出最新按键 |
| 同一个按键重复按 | 固定对应同一种颜色、动画类型和基本音色，使孩子能发现规律；运动方向可略有变化 |
| 长按 | 当前实现一次按下只触发一次，不自动重复，不在按住期间朗读 |
| 退格 | 删除本轮最后一个字符，并让被删除字符缩小消失 |
| 输入很长 | 底部显示最后 12 个字符；当前输入缓冲上限 24，超长本轮不朗读 |
| 停止输入 | 从全部按键松开开始，默认等待 **3 秒**，每次新按键重新计时 |
| 停顿结束且整轮是词库内单词 | 显示对应图案和单词，英语朗读一次，然后该轮输入已清空 |
| 停顿结束但未匹配 | 不朗读、不报错，结束并清空本轮输入 |
| 朗读时又按键 | 立即打断朗读，开始新一轮声音和动画反馈 |

“如果是单次”已由用户确认实际指 **“如果是单词”**。
不是只按一次就读字母，也不是把每个键映射成固定单词进行朗读。

只匹配整轮输入：`cat` 可以触发，`xxcat`、`cat1`、`cat dog` 都不能自动截取出 `cat`。
第一版使用有限的离线词库，不承诺识别所有英文单词。词库见 [`assets/words.txt`](../assets/words.txt)。

## 声音偏好

用户最新要求：**适合小孩，需要宁静柔和**。

- 声音要清楚可听、有趣、舒缓。用户反馈过上一版“按键音听不见，但英文朗读有声音”，因此柔和不能以牺牲可听性为代价。使用圆润水滴、柔和钢琴、轻木音和轻微的摇篮曲和声等方向。
- 避免刺耳的高音、突然炸开的响声、夸张的弹簧颤动和不断积压的声音队列。
- 同一键的音色与音高关系保持稳定；不要恢复成每次完全随机的声音。
- 英文朗读应清楚、轻一些、慢一些。用户没有明确要求模仿婴幼儿人声；目前使用柔化的英语女声。
- 素材响度与设备实际音量都需要考虑；设备保存过的音量会覆盖代码默认值。
- 按键音与英语语音使用独立通道增益，切换时停止另一通道，避免叠加。可以通过家长设置调整音量，调整时立即试听；实际听感以设备上的试听反馈为准。

## 画面偏好

- 大字母、清楚的颜色和简单的图案，适合小屏幕观看。
- 当前键动画与输入内容明确关联，底部累计输入保持可读。
- 泡泡、弹跳球、花朵、星星可以保留；画面活泼，但避免频繁全屏闪烁。
- 孩子界面保持直接。等待时间、音量、亮度放在家长设置中，不要求孩子操作菜单。

## 当前实现参数（可继续调整）

| 项目 | 当前值 |
| --- | --- |
| 默认停顿时间 | **3000 毫秒**；用户把原来的 5 秒改为了 3 秒 |
| 可配置等待范围 | 家长设置 1–15 秒；USB 可设置该范围内的毫秒值 |
| 默认音量 | **80/255**；按键音恢复清晰中频，朗读通道单独衰减以保持原有柔和响度 |
| 音量设置上限 | 160/255 |
| 默认亮度 | 130/255 |
| 闲置渐暗 | 默认 60 秒，可选关闭/30/60/120 秒；1.5 秒渐变到亮度 20，首键立即恢复并照常输入 |
| 家长设置入口 | 长按 G0 / BtnA 约 2 秒；W/S 选择、A/D 调整、Enter 保存、反引号取消 |
| 离线词库 | 当前 143 个常见英文单词，121 种图案；同义词共用语义相关图案 |
| 按键音效 | 4 类 × 5 个音高，共 20 段；基础音高约 523–880 Hz，12–24 毫秒渐入 |
| 英语语音 | macOS Samantha，本机生成；135 词/分钟后以 0.9 倍速保留音调减速并降低响度 |
| 存储 | 音频嵌入固件；家长设置保存到 NVS，断电保留 |

这些参数位于 [`include/toy_config.h`](../include/toy_config.h)、
[`scripts/generate_audio.py`](../scripts/generate_audio.py)、[`include/parent_settings.h`](../include/parent_settings.h) 和设备持久化设置中。
安装、构建、刷写、调试、备份恢复方法见 [`README.md`](../README.md)。

## 协作与验证

- 遇到会改变产品含义的歧义，应先分析并确认；用户明确要求先分析时，不直接实施。
- 已确认的需求持续有效。实施应完成代码、素材、配置、合适的测试和授权的设备验证。
- 涉及默认值时核对设备实际配置，尤其是停顿时间、音量；保留无关的已保存设置。
- 真机自动测试默认静音，仍运行真实播放链路；结束时先停止播放、排空缓冲，再恢复正常音量，不修改已保存音量。用户敲按会改变输入和计时，应提前提醒静置；人工试听与自动验证分开进行。
- 报告客观验证结果，并诚实区分“播放接口成功”“音频参数已检查”和“用户实际听起来满意”。
- 保留恢复路径，不覆盖首次原固件备份。用项目内环境重复构建，避免依赖未经记录的全局改动。

## 回归保护与工具偏好

- 保留输入计时、长按、退格、精确匹配和打断朗读等既有回归用例。新增声音可听性参数、词库与图案完整性、四类动画运动和输入栏稳定性检查。
- 测试应验证行为边界，避免把特定波形或像素快照作为永久不变的产品要求。自动用例不替代真实听感确认。
- 用户要求移除代码知识图谱 MCP 功能与对应 skill，后续不主动恢复；改用普通文件和文本搜索。

## 1.4：用户确认的 MVP 后续功能

用户确认按“单词专属情景动画、家长英语图鉴、闲置渐暗”三项方向实施。

- 情景动画：蝴蝶扇翅、鸟儿振翅、鱼吐泡泡、花瓣轻摆、爱心跳动、雨滴下落、火箭尾焰和星光、睡觉时漂浮的 Z、火车和卡车车轮转动。它们用于匹配单词后的展示，也用于英语图鉴。
- 英语图鉴：长按 G0 进入家长设置，选 Picture book 后 Enter 打开。A/D 前后翻页、W/S 跳 10 页，首尾循环；默认安静浏览，Enter 才朗读当前词，反引号回到设置。图鉴不累积儿童输入、不自动朗读、不在 4.5 秒后退出；退出后仍遵守原有 3 秒精确匹配规则。
- 闲置渐暗：默认 60 秒无操作后，用 1.5 秒逐渐降到亮度 20/255；可选关闭、30、60、120 秒。按键立即恢复正常亮度，第一下按键仍产生正常输入与声音；长按期间保持亮屏。只调整背光，不进入需要特殊唤醒方式的深睡眠。
- 设置升级：旧版的 3 秒停顿、音量和亮度迁移保留；新版设置单个 blob 保存于 settings_v2，避免多字段分别写入造成部分更新。
